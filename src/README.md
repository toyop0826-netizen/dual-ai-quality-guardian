1. システム全体の概要
Dual-AI Quality Guardianは、AIによる画像検査とロボットシミュレーションを組み合わせた品質検査システムの実証プロジェクトです。

主に次の5つの機能から構成されています。

【① 画像取得・録画】
Gazebo上のカメラ画像やシミュレーション映像を取得します。

【② AIによる品質判定】
OpenAIとGeminiを利用して、検査対象をGOOD・DEFECT・REVIEWに分類します。

【③ ロボット動作検証】
GazeboとROS 2などを利用して、ロボット動作や対象物の移動量を検証します。

【④ 動画・報告資料の作成】
実際のシミュレーション映像と測定データを組み合わせ、提出用の動画や説明資料を作成します。

【⑤ 証跡・品質保証】
実行結果、測定データ、AI判定結果などを保存し、SHA-256を使ってファイルの整合性を検証します。

※以下では、実際にコード本文を確認済みのものを【確認済み】、ファイル名や開発履歴から役割を推定しているものを【推定】と区別します。
